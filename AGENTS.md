# tw Map Editor

This repository is an independent map-authoring tool. Preserve authored maps and imported local libraries. Do not commit `local/`, `web/maps/` user files, imported game models/textures, player saves, secrets or machine-specific paths.

The public `web/data/`, `web/models/` and `web/thumbnails/` contain original procedural demo assets generated by `tools/make-demo.py`. Preserve Third-party notices and `web/vendor/LICENSE` when modifying vendor files.

Keep the map format, server validation and browser validation aligned. Tests should cover meaningful preservation / format changes. Run `node --test tests/model.test.mjs` and `python -m unittest discover -s tests -p "test_*.py"`; browser flows use `tests/browser.mjs`.

The server binds to loopback. Imported libraries are read-only. Project saves create new files in `web/maps/` and never overwrite existing projects. Do not claim exported maps are integrated into a game or native `.d2m` files.
